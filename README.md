# 🌲 Random Forest Regressor

A user-friendly machine learning web application built with **Python, Scikit-learn, Pandas, and Streamlit** that allows users to train and use a **Random Forest Regression model** directly through an interactive web interface.

The application provides an easy way to upload a dataset, select the target variable, configure Random Forest parameters, train the model, evaluate its performance, and generate predictions.

## 📌 Project Overview

Random Forest Regression is an ensemble machine learning technique that combines multiple decision trees to make accurate predictions for continuous target variables.

This project converts the traditional machine learning workflow into an interactive web application, allowing users to perform regression without directly writing Python code.

### The application allows users to:

- 📂 Upload a CSV dataset
- 🎯 Select the target column
- 🌳 Configure the number of trees
- 📏 Set the maximum tree depth
- 🧪 Adjust the test size
- 🔀 Set a random state
- 🤖 Train a Random Forest Regression model
- 📊 Evaluate model performance
- 🔮 Generate predictions
- 📋 View the uploaded dataset

---

## ✨ Features

### 📂 Dataset Upload
Users can upload their own CSV dataset through the Streamlit interface.

### 🌲 Random Forest Configuration

The application provides controls for important Random Forest parameters:

| Parameter | Description |
|---|---|
| Number of Trees | Number of decision trees used by the model |
| Maximum Tree Depth | Controls the maximum depth of each decision tree |
| Test Size | Percentage of data used for testing |
| Random State | Ensures reproducible results |

### 📊 Dataset Preview

After uploading a CSV file, the application displays the dataset in an interactive table, allowing users to inspect their data before training the model.

### 🤖 Machine Learning Model

The application uses:

**RandomForestRegressor** from Scikit-learn.

The model learns relationships between the input features and the selected target variable to make continuous-value predictions.

### 📈 Model Evaluation

The trained model can be evaluated using common regression metrics such as:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score
